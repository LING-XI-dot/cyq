三维动画作业

我做的内容是以minecraft这款游戏为参考风格，制作一个女孩准备出行，展示大陆的风采。在建模上我借助了Modelbench，制作方法为导入平面皮肤图片，再分别创建平面组合 
此处借用了朋友的皮肤文件
在完成模型制作之后，导出obj文件，导入blender，并进行骨骼的绑定
 
除了人物还需要场景的建造，在自己建造地图的同时，我运用了mineways来提取模型  
之后对场景颜色进行微调，对不同物体进行分离，之后便可以单独在着色器内调整颜色 
  
调整完大体颜色之后就是打光，先是新建了一个立方体加入景深，之后就是正常打光添加光源
 
对光源颜色进行了调整更像太阳光
之后就是基本的关键帧
 
人物的运动添加了路径，编辑了贝塞尔曲线，作为人物运动的基础
在后续物品放置的片段，将物品跟手建立子级，并且在出现和消失的帧上进行修改，达到拿取和放置的目的
后续基本上为重复过程，不多做赘述
